# # TW Stock Screener

Automated stock screening for Taiwan stocks using technical indicators (RSI, MACD, Bollinger Bands).

## Features
- Uses Yahoo Finance API
- - Automated scheduling
  - - Line Notify integration
    - - Customizable stock list
     
      - ## Setup
      - 1. Get Line Notify Token
        2. 2. Add LINE_TOKEN to GitHub Secrets
           3. 3. Deploy to GitHub and use GitHub Actions for scheduling.
