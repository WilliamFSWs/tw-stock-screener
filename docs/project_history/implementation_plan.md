# 價量關係分析 — 7日上漲80%勝率模型

從歷史數據中找出「買進後 7 日內上漲」的高勝率價量訊號，推導出可量化的公式。

## 分析方法

### 研究的價量模式（Patterns）

從圖表觀察到的常見反彈訊號，將逐一回測：

| # | 模式名稱 | 描述 |
|---|---------|------|
| 1 | 量縮價穩 | 成交量連續萎縮至低於 MA20 的 50%，但股價跌幅收窄 |
| 2 | 量增突破 | 成交量突增超過 MA5 的 2 倍，且收紅 K |
| 3 | 均線支撐 + 爆量 | 股價回測 MA20 附近 (±2%) 且成交量 > MA5 |
| 4 | 下影線 + 放量 | 下影線長度 > 實體 2 倍，且成交量 > MA20 |
| 5 | 連跌後量縮紅K | 連跌 3+ 日後出現紅 K，且成交量 < MA5 |
| 6 | 價量背離 | 股價創近期新低，但成交量低於前次新低時的量 |
| 7 | 組合訊號 | 結合多個弱訊號組成複合條件 |

### 回測框架

1. **資料來源**：用 `yfinance` 抓取近 2 年日K歷史資料
2. **訓練集**：用 2330.TW（台積電）發現模式
3. **驗證集**：用 2308.TW（台達電）、2454.TW（聯發科）驗證
4. **勝率計算**：每次訊號觸發後，檢查 T+1 ~ T+7 內最高價是否 > 買入價
5. **輸出**：各模式的勝率、平均報酬、最佳組合公式
