# 📜 專案開發對話與決策日誌 (Taiwan Stock Screener)

本文件摘要記錄了開發過程中的重大決策、策略調整與系統演進，方便隨時在雲端查閱。

## 📅 最近更新：2026-02-23

### 1. 核心邏輯演進：保守進場策略
*   **決策背景**：為了解決追高風險與回測真實性的問題。
*   **調整內容**：
    *   **D+1 進場**：買入點改為訊號隔日的開盤價 (`open.shift(-1)`)。
    *   **排除跳空 (No Gap-up)**：若 D+1 開盤價大於 D+0 收盤價，則放棄該筆交易，不計入勝率回測。
*   **成果**：全市場實測證實，「不追高」策略能將熊市 (2022) 的勝率從 ~91% 提升至 **95%~98%**。

### 2. 勝率評分系統 (Win Rate Score)
*   **決策背景**：量化個股推薦強度，協助使用者快速篩選。
*   **公式組成**：
    *   量縮價穩 (P01) / 量增紅K (P02) / 連跌反轉 (P05) 權重分配。
    *   **紅利加分**：站上 MA60 (+10)、三線合一 (+15)、波動率壓縮築底 (+20)。
*   **應用範圍**：整合至每日掃描 CSV 與 LINE 即時診斷通知。

### 3. 全市場大數據資料庫 (2020-2025)
*   **架構**：將台股 1,078 檔股票按市值排名分為 5 個 Group。
*   **數據格式**：本地 CSV 存儲，支援秒級回測，不需重複下載。

### 4. 自動化分析流水線
*   **GitHub Actions**：每日 09:05 與 15:30 自動執行掃描。
*   **效能優化**：採「先掃描再截圖」模式，將 top 500 檔的執行時間最佳化至數分鐘內。
